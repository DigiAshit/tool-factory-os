# MVP Specification Template - Product Engine

Use this template to specify the initial MVP layout for approved opportunities.

---

## 1. Problem Definition
- **The Core Pain**: [What is the single, most painful manual task we are automating?]
- **Target User**: [Who is the core user? e.g. Freelance SEOs, agency owners]
- **The Niche Hook (Great at One Thing)**: [What is the single feature where our product must be world-class? E.g., Tweet Hunter is excellent at finding viral inspiration; below average at standard tweet drafting UI.]

## 2. Technical Architecture & Moats

### A. Modular AI Engine
- **Swap-ready Interface**: [Define the API interface abstraction that allows plugging in new models (e.g., swapping OpenAI to Anthropic or Google API in 10 lines of config).]
- **Next-Gen Preparedness**: [How are we building with the AI quality of tomorrow in mind? e.g. assuming multimodal input or faster processing.]

### B. Non-AI Core Feature (The Moat)
- **The Proprietary Moat**: [What is the non-AI feature that protects us from base models building this into their platforms? E.g. a powerful custom video editor, a specialized community dataset, a template library.]
- **Exit Viability**: [How does this feature serve as a standalone asset for an acquisition/exit?]

## 3. Product Skeleton (Month 1-2)
- **The Core Feature Only**: [Describe the absolute minimal interface. No settings, no dashboards, no custom colors. One input, one button, one output.]
- **Ugly but Stable Checklist**:
  - [ ] Main action runs in <10 seconds.
  - [ ] No database needed if local storage suffices.
  - [ ] Error messages are plain text but accurate.

## 4. Launch & Success Metrics
- **Validation Users**: [List the 5-10 users who will receive free access in Week 1.]
- **Activity Target**: [The skeleton is successful if 5+ of these users use it at least twice in a week.]
- **Pricing Hypothesis**: [What will we charge? e.g. $19/month flat.]
