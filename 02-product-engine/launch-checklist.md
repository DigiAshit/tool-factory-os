# Launch Checklist - Product Engine

This document defines the essential steps for moving from a verified skeleton into the Broadcast Phase.

## 1. Landing Page (Distribution-First)
- [ ] **Single benefit headline**: Make the headline focus on a specific different position, not generic superiority.
- [ ] **No stock images**: Use real screenshots of the skeleton or a simple 10-second walkthrough video.
- [ ] **No marketing fluff**: Write as a human builder. "I built this tool because I was tired of X. Here is what it does."
- [ ] **Journey connection**: Add a link to your X/LinkedIn profile. Invite people to follow the build journey.

## 2. Analytics & Feedback Systems
- [ ] **Simple usage tracking**: Install basic analytics (e.g. Mixpanel, Plausible, or a simple database log) to count action triggers.
- [ ] **The "Use Twice" tracker**: Configure tracking to identify if the same user token/cookie triggers the core action on separate days.
- [ ] **Feedback widgets**: Add a simple feedback box or a Discord/WhatsApp direct contact link on the page. Make it trivial for users to talk to the builder.

## 3. Pricing Verification
- [ ] **Stripe checkout**: Integrate a single payment link or simple subscription portal.
- [ ] **No billing complexity**: Avoid tiered pricing. Use a single flat rate (e.g. $19/mo or $49/year).
- [ ] **Refund assurance**: Guarantee refunds on request. Keep transaction friction low to encourage adoption.
