# Feedback System - Growth Engine

This document defines how we collect, catalog, and action user feedback.

## 1. Feedback Channels
- **In-App Widget**: A simple, frictionless text input box in the footer.
- **Direct Link**: A prominent link to a Telegram group, WhatsApp chat, or the founder's DM.
- **Bi-Weekly Calls**: Offer $20 Amazon vouchers or free access extensions for a 15-minute screen-share feedback session with active users.

## 2. Categorization Rubric
All feedback must be logged in the product log under three categories:
1. **Core Friction (Actionable)**: Issues preventing completion of the primary workflow (e.g. "Export button fails to render on Safari").
2. **Expansion Requests (Backlog)**: Features extending the workflow (e.g. "I want to schedule this directly from the page").
3. **Vanity Requests (Ignore)**: Requests that do not increase retention or revenue (e.g. "I want to change the color theme of my dashboard").

## 3. The Feedback-to-Build Loop
- Only implement features that solve **Core Friction** or have **explicit demand** from 3+ paying customers.
- If a feature is requested but does not align with the product being different or solving one core problem, politely decline or suggest a workaround.
