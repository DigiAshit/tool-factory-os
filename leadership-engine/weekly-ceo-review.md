# Leadership Engine - Weekly CEO Review SOP

## 1. Trigger
Executed by the **CEO** every Monday morning.

## 2. Weekly Metrics Review Checklist

### Step 2.1: Gather the Core Scorecard
Review the central scorecard metrics across the portfolio:
1. **Opportunities Scored**: Target $\ge 5$ new frustrations scored in the scoring framework.
2. **Opportunities Validated**: Target $\ge 1$ project entering the Week 1 Validation phase.
3. **Active MVP Builds**: Strict limit of **1 MVP** under development.
4. **Cohort Churn**: Audit Stripe churn logs. Ensure WAU subscription churn is $< 8\%$ for all scaled assets.

### Step 2.2: Decision Gate Audits
1. **Validation Gates**: Verify all ideas in the validation phase.
   - Did the project get 10+ unprompted leads within 7 days? If yes, proceed to spec. If no, trigger the immediate kill/archive action.
2. **Month 2 Skeleton Gates**: Check projects in Month 2.
   - Have at least 5 testers run the core workflow at least twice? If yes, approve feature expansions. If no, freeze coding additions and focus purely on quality/latency.
3. **SOP Compliance**: Check if any new processes were run without being documented. Instruct the SOP Manager to draft missing SOPs.
